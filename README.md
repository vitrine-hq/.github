# .github

Public organization profile for [Vitrine](https://github.com/vitrine-hq).

- `profile/README.md` is rendered on the organization page.
- `profile/assets/` holds the logo files used by the profile.

This repository must stay public for the profile to render. Do not add internal information here (private repository details, infrastructure URLs, customer or business data). Members-only content belongs in a private `.github-private` repository.
